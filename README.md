# 🍕 Pizza Order System - Desktop Application

A desktop point-of-sale and order management application built with C# and Windows Forms, enabling dynamic pizza customization, real-time price calculation, and instant order summary generation.

---

## 📋 Project Metadata
- **Project Type:** Desktop Application (Windows Forms)
- **Language & Framework:** C# (.NET Framework)
- **UI Framework:** Windows Forms (WinForms)
- **Programming Paradigm:** Object-Oriented Programming (OOP) & Event-Driven Programming

---

## ✨ Key Features
- **Custom Pizza Builder:** Select pizza size (Small, Medium, Large), crust type (Thin, Thick), and multiple toppings (Extra Cheese, Mushrooms, Olives, Onions, Tomatoes, Green Peppers).
- **Dynamic Real-Time Pricing:** Automatic recalculation of the total price upon every option or topping change without requiring manual refresh.
- **Order Type Selection:** Choose between **Eat In** and **Take Out** options.
- **Live Order Summary:** Automatically updates and displays a clean summary of all selected items and the final bill.
- **Order Confirmation & Reset:** Lock selections upon order confirmation and reset the interface with a single click for the next customer.
